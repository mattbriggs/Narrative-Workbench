Narrative Workbench is a proposed environment for designing stories, studying existing works, and exploring how a change to one narrative condition affects the rest. It models events, world state, character beliefs, reader expectations, and narrative form before turning an accepted trajectory into prose.

## Status

**Design stage.** No runnable application, installation procedure, automated test suite, or release has been committed yet. The architecture and interface specifications are drafts, and implementation decisions remain open.

## Design direction

- **Composition Studio:** Arrange narrative conditions, explore possible event trajectories, review their effects, and develop prose from an accepted trajectory.
- **Criticism Parlor:** Reconstruct interpretations of an existing work, link claims to source evidence, and compare competing readings.
- **Counterfactual Laboratory:** Branch from a narrative or interpretation, change a controlled condition, and inspect the resulting differences without overwriting the source.

The proposed shared model records world events separately from what characters believe and what readers know. It also distinguishes ordinary state changes from changes to the framework through which events are interpreted. Version history, evidence, and reviewable proposals are intended to make each change traceable.

## Getting started

There is nothing to install or run yet. Watch this repository for implementation updates, or use [GitHub Issues](https://github.com/mattbriggs/Narrative-Workbench/issues) to discuss the design.
